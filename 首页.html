课程体系

三大模块，循序渐进

由浅入深的知识结构，帮你把零散的知识点连成一条完整的技能链。

第一阶段

Java 语言基础

掌握变量、运算符、流程控制、数组、面向对象编程与异常处理， 打牢后续 Web 开发所必需的语言功底。

第二阶段

HTML / CSS 前端

学会使用标签搭建页面结构，用 CSS 选择器与盒模型完成美观的 页面布局，并实现响应式适配。

第三阶段

数据库与 JDBC

学习 MySQL 建库建表与 SQL 查询语句，通过 JDBC 让 Java 程序 与数据库真正打通，实现数据的持久化存储。
